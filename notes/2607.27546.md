# Memory Efficient Tabular Foundation Models

## One-line takeaway

## Problem

Tabular foundation models are apparently very memory intensive. Whether existing quantization methods can be employed for popular tabular foundation models is open for experimentation.&#x20;

## Core idea

A systematic study using existing quantization methods (PTQ, GPTQ) for tab models on existing datasets.&#x20;

## Method

* Models used: TabPFN v2.5 and TabPFN v2.6
* Datasets used from OpenML, a collection of 30 tabular datasets.&#x20;

## Results

Pretty awesome, PTQ and GPTQ reduced the memory from 40MB to \~5-6MB across the board and performance didnt know major regressions.&#x20;

## Limitations

* Only done on TabPFN v2.5 and v2.6, and only on post training quantization.&#x20;
* No reasoning for why the performance might've been retained.&#x20;
* They didn't include the per task results, which would've provided more context for where the models are doing well and where they're regressing.&#x20;
