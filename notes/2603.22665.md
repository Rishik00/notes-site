# Improving LLM Final Representations with Inter-Layer Geometry

## One-line takeaway

They're using GNNs as a LORA substitute?&#x20;

## Problem

A lot of post training happens in the final layers, thus pleading for newer techniques to use the intermediate layers for sending information.&#x20;

## Core idea

Model the information modelling as a graph learning problem and use dense/sparse graphs where nodes are the layers.&#x20;

## Method

### A little background on graph neural nets

A GNN or Graph Neural Network takes a graph as an input and does something called message passing between the different nodes of the said graph. Three different things happen during this statge:&#x20;

1. Information passing to other nodes.&#x20;
2. Aggregation of information recieved.
3. &#x20;Representation update by combining the aggregated messages with the previous state.&#x20;

### Now for the methodology

1. Consider an LLM that takes in T token sequences and L layers (l1...ln).&#x20;
2. The representations from each layer are mean pooled in the token dimension.&#x20;
3. Take each layer's mean pooled representation as a graph node and send that as input.&#x20;
4. To obtain a graph-level representation, the final node representations are pooled (mean/sum).&#x20;
5. A fully connected encoder takes the layer representations and maps them back to the nodes, where every layer is connected with every other layer.&#x20;

## Results

Pretty impressive! The FC encoder and cayley encoder perform substantially better at certain types of tasks across the board.&#x20;

To understand these results further, they trained the same encoders on the entire pythia lineup and the trend seems to be common - as the parameter size goes up the performance seems to get better for these new encoders, while also beating other approaches.&#x20;

They also try to further evaluate on the token level rather than the layer level. Performance seems to keep improving, but I wonder how much of the data here is noisy. (worth reproducing)&#x20;
